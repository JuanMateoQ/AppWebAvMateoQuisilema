## Fixed missing page registrations in WebAppPoliMusicV3.csproj

- Error: "No se pudo cargar el tipo 'WebAppPoliMusicV3.Login'" parser error because Login.aspx.cs, SignUp.aspx.cs and Logout.aspx.cs were not registered as Compile items
- Added Content items: Login.aspx, Logout.aspx, SignUp.aspx
- Added Compile items with DependentUpon: Login.aspx.cs + Login.aspx.designer.cs, Logout.aspx.cs + Logout.aspx.designer.cs, SignUp.aspx.cs + SignUp.aspx.designer.cs
- Root cause: existing ASPX files were physically present but omitted from the project file, so their code-behind classes were never compiled into the assembly
